# 🤝 Contributing Guide

Thank you for your interest in contributing to the **Dutch Real Estate Buyers Assistant**!

---

## 🧭 Contribution Philosophy
This project promotes **clarity**, **local-first AI**, and **open learning**.  
Contributions are welcome in documentation, code, or user experience improvements.

---

## 🛠️ How to Contribute

### 1. Fork the Repository
```bash
git fork https://github.com/akumawavez/LLMzoomcamp2025/tree/main/cohorts/2025/project/attempt2.git
```
### 2. Create a New Branch
```bash
git checkout -b feature/improvement-name
```

### 3. Make Your Changes

Follow PEP8 style guidelines and ensure code clarity.

### 4. Test Your Changes

Run locally:
```bash
streamlit run ChatApp_RAG_ollama_langchain.py
```

### 5. Submit a Pull Request

Explain what you changed and why. Attach screenshots if possible.


### 🧪 Suggested Contribution Areas

Enhancing the UI or user onboarding flow.

Adding Docker Compose setup for one-click deployment.

Improving PDF text chunking or search relevance.

Writing tutorials or expanding documentation.

### ⚖️ Code of Conduct

Be respectful and inclusive.
Constructive feedback and collaboration are encouraged.
